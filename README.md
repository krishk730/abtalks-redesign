# ABTalks Redesign

A mobile-first redesign of ABTalks built for Vicodathon.

## Problem

ABTalks runs a 60-day coding challenge where college students build something every day and submit GitHub and LinkedIn proof of work.

## Solution

This redesign focuses on making the challenge easier to understand, motivating students to stay consistent, and making daily proof submission simple.

## Required Screens

- `/` — Landing Page
- `/dashboard` — Student Dashboard
- `/day/12` — Challenge Day

## Key Features

- 60-day challenge overview
- Current streak
- Daily task
- Challenge progress
- Student standing
- Achievements
- GitHub proof
- LinkedIn proof
- Daily submission flow
- Missed-day state

## Tech Stack

- React
- TypeScript
- CSS
- Wouter

## Design

Mobile-first, optimized for a 390px viewport.
