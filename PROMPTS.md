# AI Usage Log — ABTalks Redesign

## Hackathon
Vicodathon

## Problem Statement
Redesign ABTalks

## Development Approach
The project was developed using AI-assisted coding and iterative development.

## Prompt 1 — Initial Project Setup

Create a modern responsive web application redesign of ABTalks for a hackathon. Use React with Vite and Tailwind CSS. Start with a clean mobile-first structure.

## Prompt 2 — Preview Fix

Check the current ABTalks redesign project and fix any issue causing the preview to appear blank or fail to load. Make sure the React/Vite app starts correctly, all imports are valid, there are no runtime errors, and the homepage renders properly.

## Prompt 3 — Required Screens

Build a mobile-first ABTalks redesign with three required routes:

/
 /dashboard
 /day/12

The landing page should explain the 60-day coding challenge. The dashboard should show streak, today's task, progress, completion, achievements and student standing. The challenge-day page should show the task and GitHub/LinkedIn proof submission flow.

## Prompt 4 — Manual Refinement

The generated implementation was manually reviewed and refined to keep the interface mobile-first, realistic, simple and suitable for the 390px judging viewport.

## AI-Assisted Features

AI assistance was used for:
- UI structure
- React component implementation
- Responsive styling
- Mocked challenge data
- Navigation structure
- Challenge submission flow

## Human Review

The project was reviewed and tested by the team during development. The final interface and feature decisions were selected and refined for the Vicodathon problem statement.
